# Paper Summary

AI/CS论文总结项目。从papers.cool抓取论文，用Kimi生成摘要，筛选高质量论文。

## 快速开始

```bash
# 1. 筛选论文
papers-cool-filter

# 2. 获取摘要
kimi-summary-extractor

# 3. 深度分析
read-arxiv-paper

# 4. 结构化输出
paper-summary-template
```

## 输出

- `knowledge/reports/structured_analysis_30.md` - 30篇论文结构化摘要
- `knowledge/reports/final_report_feb-2026.md` - 综合报告

## 技术栈

- Python 3.14
- papers.cool API
- arXiv TeX
