# SkillRL: Evolving Agents via Recursive Skill-Augmented Reinforcement Learning

## 基本信息
- arXiv ID: 2602.08234
- 作者: 待确认

## 核心方法

**研究背景**：大型语言模型（LLM）智能体无法有效从经验中学习并迁移知识，每次交互都视为独立事件，无法从过去的成功或失败中提取可复用的知识。

**核心问题**：
1. 经验学习的孤立性：现有LLM智能体以孤立、非累积的方式执行任务
2. 原始轨迹存储的冗余与噪声：轨迹冗长、高噪声、低抽象性
3. 缺乏层次化的技能抽象

**核心方法 - SKILLRL框架**：

1. **基于经验的技能蒸馏机制**：通过教师模型对轨迹进行差异化处理
   - 成功轨迹 → 战略模式（捕获关键决策与可迁移模式）
   - 失败轨迹 → 失败教训（包含失败点、错误推理及预防原则）
   - 实现10-20倍的token压缩

2. **层次化技能库构建（SKILLBANK）**：
   - 通用技能（跨任务战略指导）
   - 任务特定技能（领域专用启发式）
   - 通过语义相似度自适应检索

3. **递归技能演化机制**：
   - 冷启动SFT：使基础模型习得技能检索与应用能力
   - 动态演化：分析失败轨迹，识别未覆盖模式并生成新技能
   - GRPO算法优化策略

## 实验结果

**主实验结果**：
| 方法 | ALFWorld | WebShop |
|------|---------|---------|
| GPT-4o | 48.0% | 23.7% |
| Gemini-2.5-Pro | 60.3% | 35.9% |
| SimpleMem+GRPO | 62.5% | 46.9% |
| **SKILLRL** | **89.9%** | **72.7%** |

**关键数据点**:
- 性能提升: ALFWorld上提升12.3%（相比基础GRPO），超越GPT-4o达41.9%
- 资源消耗: 上下文长度减少约10.3%
- 对比基准: 搜索增强QA任务达到47.1%平均得分

**消融实验**：
- 移除层次结构：性能下降13.1%
- 替换为原始轨迹：性能下降28.2%
- 移除冷启动SFT：性能下降24.7%
- 移除动态演化：性能下降5.5%

**技能库演化**：
- 初始55个（12通用+43特定）→ 150步时增长至100个（20通用+80特定）
- 收敛速度：60步内达到80%成功率

## 关键贡献

1. **技能抽象范式**：证明将经验蒸馏为结构化技能优于原始轨迹存储
2. **递归协同演化**：首创在RL训练期间动态更新技能库的机制
3. **实用性能提升**：以7B参数模型超越大规模闭源模型
