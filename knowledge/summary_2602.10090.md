# Agent World Model: Infinity Synthetic Environments for Agentic Reinforcement Learning

## 基本信息
- arXiv ID: 2602.10090
- 作者: 待确认

## 核心方法

**研究背景**：智能体强化学习面临环境稀缺、多样性不足且难以扩展的核心问题。真实环境成本高昂，人工环境缺乏多样性，LLM模拟环境存在幻觉且效率低。

**核心方法 - Agent World Model (AWM)**：

1. **分层渐进式合成架构**：
   - 场景生成：从100个种子域名扩展至1,000个多样化场景
   - 任务生成：为每个场景合成10个具体用户任务
   - 数据库设计：生成SQLite模式定义状态空间
   - 接口合成：生成MCP兼容Python接口层，平均35个工具/环境
   - 验证合成：生成Python验证函数，支撑奖励函数设计

2. **代码驱动与状态一致性保障**：
   - 使用SQLite作为结构化关系型后端
   - 通过MCP协议统一交互范式
   - 支持1,024并发环境实例

3. **代码增强的LLM-as-a-Judge验证**：
   - 代码验证：执行预生成验证代码
   - LLM判断：综合判断任务完成状态

4. **历史感知训练对齐**：
   - 在GRPO训练中采用滑动窗口历史截断
   - 优化策略条件于截断历史

## 实验结果

**BFCLv3基准对比**：
| 方法 | 8B模型得分 |
|------|-----------|
| Base | 53.83 |
| Simulator | 52.53 |
| EnvScaler | 36.83 |
| **AWM** | **65.94** |

**τ²-bench与MCP-Universe**：
- AWM在所有基准上均持续提升
- 显著优于Simulator和EnvScaler

**环境规模扩展**：
- 10个环境：严重过拟合，性能崩溃
- 100个环境：大幅提升
- 526个环境：持续单调提升

## 关键贡献

1. 首个全自动可执行环境合成框架
2. 生成1,000个环境、35,062个工具、10,000个任务
3. 代码增强的LLM验证机制，对不完美环境具有容错能力
4. 提供目前规模最大的开源工具使用环境集
