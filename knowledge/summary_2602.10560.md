# GRU-Mem: When to Memorize and When to Stop - Gated Recurrent Memory for Long-Context Reasoning

## 基本信息
- arXiv ID: 2602.10560
- 作者: 待确认

## 核心方法

**研究背景**：现有循环记忆方法存在两个关键局限：记忆爆炸风险（无关块累积噪声内容）和缺乏退出机制（必须处理所有块）。

**核心方法 - GRU-Mem**：

1. **双门控机制**：
   - **更新门（Update Gate, U_t）**：决定是否用候选记忆更新当前记忆
     - U_t = True：更新记忆 M_t ← M̂_t
     - U_t = False：保留旧记忆 M_t ← M_{t-1}
   - **退出门（Exit Gate, E_t）**：决定是否终止循环
     - E_t = True：立即终止，生成答案
     - E_t = False：继续处理下一个块

2. **端到端强化学习训练**：
   - 更新奖励 r_update（轮次级）：
     - 包含证据的块：U_t=True奖励+1，否则-1
     - 不含证据的块：U_t=False奖励+1，否则-1
   - 退出奖励 r_exit（轨迹级）：
     - 精确退出：奖励0
     - 过早退出：惩罚-0.75
     - 过晚退出：惩罚-0.5
   - 分层优势计算：结合轨迹级与轮次级优势

3. **推理策略灵活性**：
   - w EG（带退出门）：激活早期退出
   - w/o EG（不带退出门）：强制遍历所有块

## 实验结果

**性能与效率对比**：
| 方法 | 加速比 | 精确退出率 |
|------|--------|-----------|
| MemAgent | 1x | - |
| GRU-Mem (w/o EG) | **~200%** | - |
| GRU-Mem (w EG) | **~400%** | **~80%** |

- GRU-Mem普遍优于MemAgent，尤其在分布外任务和小模型上
- 有效避免记忆爆炸，记忆大小保持稳定低速增长

**不同上下文长度**：
- 随着上下文长度增加，GRU-Mem的加速比优势更加明显

## 关键贡献

1. 引入更新门解决"记忆爆炸"问题
2. 引入退出门实现"自适应早期退出"
3. 在保持性能的同时最高可实现**400%推理加速**
4. 首次系统研究长上下文推理中的记忆更新与终止决策的联合优化
