# On-Policy Context Distillation for Language Models

## 基本信息
- arXiv ID: 2602.12275
- 作者: 待确认

## 核心方法

**研究背景**：LLM的上下文知识是短暂的，会话结束后丢失。传统上下文蒸馏方法依赖离线训练和前向KL散度，存在暴露偏差和模式覆盖行为问题。

**核心方法 - OPCD（在线策略上下文蒸馏）**：

1. **在线策略学习**：
   - 学生模型基于自身生成的轨迹进行训练，而非教师生成的数据
   - 消除训练与推理之间的分布差异

2. **反向KL散度**：
   - 最小化学生分布与上下文条件教师分布之间的反向KL散度
   - 鼓励模式寻求行为，专注于生成教师认为高概率的token

3. **数学形式化**：
   $$\mathcal{L}(\theta) = \mathbb{E}_{(x,c)\sim D, y\sim\pi_\theta(\cdot|x)} \left[ \frac{1}{|y|} \sum_{t=1}^{|y|} D_{KL}(\pi_\theta(\cdot | x, y_{<t}) \| \pi_{teacher}(\cdot | c, x, y_{<t})) \right]$$

4. **灵活的教师配置**：
   - 教师-学生蒸馏：教师可为更大模型或冻结参数的同规模模型
   - 自蒸馏：教师与学生共享权重，仅输入不同

## 实验结果

**经验知识蒸馏（数学任务）**：
| 方法 | 测试准确率 |
|------|-----------|
| Base Model | 75.0% |
| In-Context | 77.6% |
| Context Distillation | 78.5% |
| **OPCD** | **79.7%** |

**系统提示蒸馏（医疗任务）**：
| 模型 | OPCD提升 |
|------|----------|
| Llama-3.1-8B | +1.5% |
| Llama-3.2-3B | +5.3% |

**跨规模蒸馏**：
- Qwen3-8B教师生成的经验可有效蒸馏到Qwen3-1.7B/4B学生
- 直接注入小模型上下文反而降低性能

## 关键贡献

1. 首次将在线策略蒸馏范式专门适配于上下文内化问题
2. 通过反向KL散度实现模式寻求行为，避免幻觉
3. 支持有效的跨规模知识迁移
4. 在数学、游戏、医疗、安全任务上均优于离线蒸馏方法
