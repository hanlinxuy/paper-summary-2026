# GLM-5: Efficient Agentic Engineering with Sparse Attention

## 基本信息
- arXiv ID: 2602.15763
- 作者: 智谱AI与清华大学

## 核心方法

**研究背景**：LLM从被动知识库向主动问题解决者转变时，训练与推理成本、真实世界适应性是主要瓶颈。

**核心方法 - GLM-5**：

1. **深度稀疏注意力（DSA）**：
   - 采用DeepSeek Sparse Attention替代传统稠密注意力
   - 通过闪电索引器动态检索top-k相关键值对
   - 128K长上下文处理的GPU成本降低50%

2. **多潜在注意力优化（MLA）**：
   - 结合Muon Split技术改进MLA
   - 576维潜在KV缓存性能匹配2048维GQA-8

3. **异步强化学习基础设施**：
   - 构建slime框架扩展版，分离推理引擎与训练引擎
   - PD分离：预填充与解码分离至专用资源
   - Token-in-Token-out网关保留精确动作-奖励对齐

4. **多阶段训练流程**：
   - 监督微调（SFT）：引入交错思考、保留思考、轮级思考模式
   - 推理RL：基于GRPO+IcePop算法
   - 智能体RL：超过10K个SWE和终端任务环境
   - 在线跨阶段蒸馏：防止灾难性遗忘

3. 构建异步RL基础设施支持大规模长时程智能体轨迹探索
