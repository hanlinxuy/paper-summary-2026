# DreamZero: World Action Model for Robot Generalization

## 基本信息
- arXiv ID: 2602.15922
- 作者: 待确认

## 核心方法

**研究背景**：VLA模型在物理动作泛化和数据效率方面存在局限性。

**核心方法 - DreamZero**：

1. **联合视频-动作建模架构**：
   - 基于预训练视频扩散模型（Wan2.1-I2V-14B）构建
   - 端到端联合训练视频预测与逆动力学模型
   - 14B参数模型继承互联网视频的时空物理动力学知识

2. **自回归生成与闭环校正**：
   - 分块自回归架构（每块2个视频帧+对应动作）
   - KV缓存机制支持任意长度序列
   - 闭环误差消除：用真实观测替换预测帧输入KV缓存

3. **流匹配训练与解耦噪声调度（DreamZero-Flash）**：
   - 视频时间步偏向高噪声状态
   - 动作时间步保持均匀分布
   - 单步去噪推理，延迟从5.7秒降至150ms（38倍加速）

4. **多样化数据学习**：
   - 约500小时多样化、非重复真实世界数据
   - 22个真实环境，强调任务多样性而非重复

## 实验结果

**零样本泛化（AgiBot平台）**：
| 任务类型 | DreamZero | 最佳VLA基线 |
|----------|-----------|-------------|
| 已见任务 | 62.2% | 27.4% |
| 未见任务 | 39.5% | 16.3% |

- 零样本泛化能力比SOTA VLA提升超过2倍

**跨具身迁移**：
| 数据类型 | 性能提升 |
|----------|----------|
| 人类视频（12分钟） | 41.8% |
| 机器人视频（20分钟） | 44.6% |

- 仅需30分钟新机器人玩耍数据即可适应全新形态

**实时控制**：
- DreamZero-Flash支持7Hz闭环控制
- GB200上推理延迟150ms/块

## 关键贡献

1. 将动作学习从直接模仿转变为基于视觉未来预测的逆动力学学习
2. 首次实现14B视频扩散模型的实时机器人控制（7Hz）
3. 利用视频模态的具身无关性实现高效跨具身迁移
4. 在真实机器人实验中零样本泛化能力比SOTA VLA提升超过2倍
