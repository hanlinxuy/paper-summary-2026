# Unified Latents: Learning Latent Representations for Diffusion Models

## 基本信息
- arXiv ID: 2602.17270
- 作者: 待确认

## 核心方法

**研究背景**：潜在扩散模型面临信息内容控制与重建质量权衡问题。

**核心方法 - Unified Latents (UL)**：

1. **固定噪声编码**：
   - 编码器输出确定性潜在表示，添加固定量高斯噪声
   - 对数信噪比λ(0)=5，而非学习可变方差
   - 简化KL散度项为加权MSE损失

2. **先验与编码对齐**：
   - 扩散先验的最小噪声级与编码器噪声显式关联
   - 获得紧致的比特率上界（bits per dimension）
   - 通过损失因子（1.3-1.7）控制潜在信息容量

3. **重新加权解码器**：
   - 使用sigmoid加权ELBO损失
   - 折扣低噪声级的高频细节重建成本
   - 损失因子上加权防止后验坍塌

4. **两阶段训练策略**：
   - 阶段1：联合训练编码器、先验和解码器
   - 阶段2：冻结编码器和解码器，重新训练先验作为基础模型

## 实验结果

**ImageNet-512生成**：
| 模型 | gFID | 训练成本 |
|------|------|----------|
| UL | 1.4 | 最优权衡 |
| DiT-XL/2 | - | 更高 |
| EDM2-S/XXL | - | 更高 |

**文本到图像生成**：
| 方法 | gFID | CLIP分数 |
|------|------|----------|
| UL | 4.1 | 相当 |
| Pixel扩散 | 5.0 | - |
| Stable Diffusion | 6.8 | - |

**视频生成（Kinetics-600）**：
| 模型 | FVD |
|------|-----|
| UL | 1.3 |
| W.A.L.T | 更高 |
| MAGVIT-v2 | 更高 |

## 关键贡献

1. 提出可解释的比特率控制机制，通过损失因子和sigmoid偏置两个超参数
2. 建立潜在表示比特率与下游模型容量之间的明确权衡关系
3. 框架统一适用于图像和视频生成
4. 对潜在通道数（16-64）不敏感，16倍空间下采样表现最优
